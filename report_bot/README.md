## Automated Application Performance Report

Task: Create an automated report on key application metrics with daily delivery to Telegram.

Implementation: Developed a script that retrieves data from the database using SQL, calculates key metrics, and generates charts. The script is orchestrated as an Airflow DAG, which automatically sends the report to Telegram via a bot.

Tools used: SQL, Airflow, DAG, Telegram Bot, Seaborn, Matplotlib.

Results: Python script and screenshots of the report delivered via Telegram.
